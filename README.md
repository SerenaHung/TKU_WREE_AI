# Week 10 AI_course_HW5
## Homework · Edit a Markdown Prompt on GitHub
作業｜在 GitHub 修改一份圖像生成提示詞

## STEP
**1. Create your own private GitHub repository.**
   在 GitHub 建立自己的 Private repo。
**2. Download and upload the original prompt.** Download **geometric-art-prompt-en.md** from the class repo, upload it to your repo, and make your first commit.
   從課程 repo 下載 geometric-art-prompt-en.md，上傳到自己的 repo，完成第一次 Commit。
**3· Edit the prompt and commit again**
Change design elements and instruct the AI to include your name and student ID as a watermark when it generates the image. Then make your second commit.
修改一項設計設定，並在提示詞中要求 AI 在生成圖片時，直接將你的姓名與學號做成浮水印。再完成第二次 Commit。
**4. Generate the image and capture the Diff.** Use your revised prompt with a photo of your choice. Then open your second commit on GitHub and take a screenshot showing the red and green changes.
   使用修改後的提示詞搭配自選照片生成圖片。接著打開第二次 Commit，截圖紅色原文與綠色修改。

## Final Submission｜繳交要求
Upload one page to iClass with all of the following.
請將以下內容放在同一頁，上傳至 iClass。
- Header · Course name, student ID, and name.（頁首：課名、學號、姓名）
- AI model and version used to generate the image.（生成圖片所用的 AI 模型與版本）
- One GitHub Diff screenshot showing the original text in red and your changes in green.（一張 GitHub Diff 截圖，須看得到紅色原文與綠色修改）
- One generated image with your name and student ID clearly visible on the image itself.（一張生成圖片，圖片上須清楚顯示姓名與學號）
